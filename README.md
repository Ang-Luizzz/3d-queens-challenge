# 3D Queens Challenge

Interactive browser puzzle for placing the maximum number of non-attacking queens in 3D chess spaces.

Current puzzle sizes:
- 3×3×3
- 4×4×4
- 5×5×5

The game runs entirely in the browser with no backend or build step.

## Development

The live app is `index.html`. Changes pushed to `main` are intended to deploy automatically through GitHub Pages.
